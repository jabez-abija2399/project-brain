# Evaluations
One file per feature: agent/evaluations/FEAT-xxx.md, written by an evaluator session (skill `evaluate`) that tested the
RUNNING app against the criteria. Per criterion: `AC-xxx-yy: PASS|FAIL - <did> -> <saw>`; last line `VERDICT: PASS|FAIL`.
Strict mode: only a session started by the human with KIT_ROLE=evaluator may write here (and in tests/acceptance/).
