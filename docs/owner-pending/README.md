# Owner-pending changes

Ready-to-apply copies of files that only the owner may change (CI workflows, `scripts/verify.sh`, protected kit
files, release files). Each folder belongs to a numbered entry in [../owner-actions.md](../owner-actions.md), which
says where the file goes, how to apply it from the GitHub website, and how to check it worked.

Claude never edits the real files; it edits these copies through normal pull requests.
