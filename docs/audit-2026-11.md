# Audit 2026-11: every page, route, API endpoint and CLI command

Date: 2026-11-01. Walked as (a) a signed-out visitor, (b) a new user, (c) a returning user with data, (d) another user
trying to reach someone else's data, and (e) an admin. Method: every page under `apps/web/src/app`, every
`route.ts` (inventory below, with the guard each one calls), every CLI command in `packages/cli/src/index.ts`, and
every promise on the landing page, the privacy page and the quickstart, checked against the code and the tests.

Severity: **HIGH** = a promise or protection that is broken; **MEDIUM** = a user gets stuck, misled or sees a broken
state; **LOW** = polish or a known limit. Every HIGH and MEDIUM item is fixed in this PR with a test; LOW items are in
`agent/later.md`.

## Promises checked and found true

- Landing: receipts from git and code-free evidence; masked secrets (first 4 characters + ***); RLS "cannot confirm";
  per-agent automation in the tabs; free during the beta; source code never stored (no column holds file contents).
- Privacy: what is stored and never stored; tokens stored as hashes; deletion (now true); no analytics trackers.
- Quickstart: `npx codeceipt` device flow, the summary lines, `codeceipt last`, `codeceipt receipt` for OpenCode and
  Antigravity.
